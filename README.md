# Refactory-Capstone-Project
# Online Retail Repeat Purchase Prediction

## Problem Statement

Can customer transaction history be used to predict whether a customer
will make another purchase within 90 days?

## Dataset

UCI Online Retail II

## Machine Learning Task

Binary Classification

## Target

Repeat purchase within 90 days

## Features

- Recency
- Frequency
- Monetary value
- Average order value
- Unique products
- Customer tenure
- Country
- Other behavioral features

## Models

- Logistic Regression
- Random Forest
- Neural Network

## Evaluation

- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- PR-AUC

## Deployment

Streamlit web application

## Business Application

Customer retention and targeted marketing.
